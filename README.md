# Brain Tumor Classification using Deep Learning

This project focuses on classifying brain tumor MRI images using Deep Learning techniques.

The project was developed and executed using a Kaggle Notebook.

## Project Overview

The goal of this project is to build an image classification model that can identify different brain tumor classes from MRI images.

The project workflow includes:

- Loading the dataset
- Exploring the image data
- Preprocessing the images
- Preparing the data for training
- Building Deep Learning models
- Training the models
- Evaluating model performance
- Comparing the obtained results
- Visualizing the model performance

## Dataset

The project uses a brain tumor MRI image dataset for image classification.

The dataset contains multiple classes of brain tumor images.

The dataset itself is not included in this repository.

## Deep Learning

This project applies Convolutional Neural Networks (CNNs) and Deep Learning techniques for image classification.

The notebook explores Deep Learning models for recognizing patterns in brain MRI images.

## Project Workflow

### 1. Data Preparation

The MRI images are loaded and prepared for the classification task.

### 2. Image Preprocessing

The images are processed and prepared as input for the Deep Learning models.

### 3. Model Training

Deep Learning models are trained using the prepared image dataset.

### 4. Model Evaluation

The trained models are evaluated using the validation/test data, and their performance is analyzed.

Training performance and model results are visualized to better understand the learning process.
